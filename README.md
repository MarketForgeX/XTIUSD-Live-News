# XTIUSD-Live-News

Live XTIUSD (WTI Crude Oil) news headlines and real-time market-related updates from multiple free sources.

## Features

- Live-style WTI / XTIUSD headline feed
- Free public RSS sources
- Automatic feed refresh via GitHub Actions
- WTI, OPEC+, EIA and Supply filters
- Headline search
- Direct links to original publishers
- White and orange trading-terminal UI
- Responsive single-page GitHub Pages design
